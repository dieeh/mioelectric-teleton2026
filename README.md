# Firmware ESP32 para Prótesis Biomecánica de Mano

Este repositorio contiene el firmware desarrollado en C++ sobre PlatformIO para el control y la gestión en tiempo real de una prótesis biomecánica de mano accionada por micro-actuadores lineales. La arquitectura de software aprovecha la capacidad de procesamiento de doble núcleo del microcontrolador ESP32 mediante el sistema operativo en tiempo real FreeRTOS, garantizando la adquisición concurrente de señales analógicas en el Núcleo 0 sin generar latencia en la máquina de estados principal que corre en el Núcleo 1.

El sistema mecánico utiliza cuatro motores DC N20 acoplados a actuadores lineales de tornillo sin fin y tuerca, gobernados por dos controladores de puente H L298N bajo una topología maestro-esclavo. El dedo índice funciona como motor maestro monitoreado en tiempo real por un encoder magnético de efecto Hall H949 conectado a las interrupciones del ESP32, mientras que los tres dedos restantes operan como esclavos imitando la señal de potencia del maestro. El control de usuario integra un joystick analógico omnidireccional con filtrado de zona muerta para ejecutar agarre de pinza y cierre de puño, complementado con la lectura continua de un sensor miroeléctrico (EMG) en el GPIO 34 para la recolección de datos y desarrollo de futuras etapas de control mioeléctrico.

Para la manipulación de objetos, el firmware integra un sistema de agarre adaptativo por detección de atasco. Si el motor está energizado pero el encoder no registra pulsos durante 150 milisegundos, el sistema asume contacto mecánico y corta la corriente por completo, sosteniendo la fuerza ejercida de forma pasiva gracias al autobloqueo del tornillo sin fin. Asimismo, el proyecto incluye una consola de telemetría e interfaz de comandos por puerto serie a 115200 baudios que permite realizar pruebas de avance, calibración de límites de carrera, inversión de polaridad por software y ajuste individual de la posición de cada dedo antes de fijar el origen cero del sistema.
